Kalkron

黒曜石とネオンの計器のような、Android 向けの電卓アプリ。

四則演算と、計算履歴の保存・閲覧。計算は BigDecimal で行うため、 0.1 + 0.2 が 0.30000000000000004 になるような誤差が出ません。

APK をダウンロード
ANDROID 8.0（API 26）以降 / 12.7 MB

機能

CALCULATE
四則演算、%、符号反転、小数点、AC / DEL、連続計算
HISTORY
計算履歴をローカル DB に保存し、一覧表示と全件削除
PRECISION
12 桁まで入力、有効桁数 12 桁で丸め（HALF_UP）。3 桁区切りで表示
SCIENTIFIC
三角関数・対数・累乗・括弧、RAD / DEG / GRAD、数値微分と数値積分
PROGRAMMER
HEX / DEC / OCT / BIN、8〜64 ビット、ビット演算・シフト・ローテート、ビット反転グリッド
LAYOUT
縦向き・横向きに対応。ダークテーマ固定

インストール

Google Play を経由しないため、端末側で「提供元不明のアプリ」の許可が必要です。

  • リリースページから最新の APK をダウンロード
  • ファイルを開き、表示に従ってインストール

個人の鍵による自己署名です。証明書の SHA-256 は 3b08f406…39e0ff0c。APK のハッシュは リリースページに記載しています。

デザイン
